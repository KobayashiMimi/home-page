# 小林 ミミ ポートフォリオサイト制作プロジェクト

このプロジェクトでは、**小林 ミミ（Mimi Kobayashi）** の写真作品を静かに鑑賞するためのポートフォリオサイト（Web写真集）を制作・ブラッシュアップしていきます。

---

## 1. プロジェクトの目的

- **既存サイトの世界観の継承と刷新**  
  STUDIOで作成された元サイト（`https://preview.studio.site/live/p6aoVVKkqR/`）が持つ静謐な空気感・タイポグラフィ・基本情報を引き継ぎながら、**PC・タブレット・スマートフォン**のすべてで美しく快適に閲覧できるレスポンシブなWebサイトとして新しく作り直します。
- **「写真集のような単調な雰囲気」の表現**  
  プロジェクト直下の `写真/` フォルダに収められた写真をもとに、過度な装飾や複雑なカテゴリ分けを排し、**1冊の写真集を静かに開いて眺めるような単調・ミニマルな体験**を作ります。

---

## 2. コンセプト・デザイン指針

1. **カラー＆トーン**
   - 背景は純黒（`#000000`）、文字色は白（`#FFFFFF`）およびオフホワイト（`#EEEEEE`）を基調とし、写真そのものが暗闇の中で静かに浮かび上がるトーンを保ちます。
2. **タイポグラフィ**
   - 上部中央に配置する縦書きの作家名「**小林 ミミ**」およびナビゲーションには `Zen Antique Soft` を使用。
   - ページ送り（`prev` / `next`）や通し番号、連絡先テキストには `Zen Old Mincho` を使用。
3. **写真の扱いとレイアウト**
   - **カテゴリ分けなしの一続き構成**: すべての写真を1冊の写真集のようにフラット・単調に並べます。
   - **トリミングなし（比率の保持）**: 縦位置・横位置それぞれのオリジナルのアスペクト比を損なわず、余白をたっぷり取って配置します。
   - **静かなグリッド一覧 ＋ 1枚ずつめくる鑑賞ビュー**:
     - ベースは余白のある静かなグリッド一覧（`index` / `large` / `sequence` の切り替え対応）。
     - 写真を選択すると1枚表示のビューアが開き、`prev` / `next`・左右タップ・キーボードの矢印キー（PC）・左右スワイプ（スマートフォン）でページをめくるように鑑賞できます。

## 4. フォルダ・ファイル構成

```text
portfolio作成/
├── README.md           # 本プロジェクトの定義書（このファイル）
├── index.html          # サイト本体（HTML）
├── css/
│   └── style.css       # デザイン・レスポンシブ対応スタイルシート
├── js/
│   ├── photos-data.js  # 写真データ定義（116枚のパス・縦横比情報）
│   └── main.js         # 画面遷移・グリッド生成・ページめくりビューア制御
├── assets/
│   ├── thumbs/         # グリッド一覧用の軽量サムネイル画像（長辺720px）
│   └── photos/         # 1枚表示用のWeb最適化高画質画像（長辺最大1920px）
└── 写真/               # 元データの高解像度写真フォルダ（原本として保持）
```

> **Note:** `写真/` フォルダ内の元データ（約534MB）は原本としてそのまま残し、Web上でPC・スマートフォンともに高速に表示できるよう `assets/thumbs/` と `assets/photos/` にWeb最適化画像を生成して読み込む仕組みにしています。

  - 閲覧体験をより写真集らしくするための細かなUI調整
